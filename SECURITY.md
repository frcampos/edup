# Política de segurança

## Reportar uma vulnerabilidade

**Não abra uma *issue* pública.** Contacte diretamente:

- Email: `frcamposri@gmail.com`
- Em alternativa: separador **Security → Report a vulnerability** deste repositório.

Indique o que observou, como reproduzir e o impacto que estima. Compromisso de resposta em **5 dias úteis**.

## Âmbito

Dentro do âmbito:

- injeção de código nas páginas do gerador ou do Arquivo (XSS);
- escrita não autorizada, adulteração ou apagamento de registos do Arquivo;
- exposição de credenciais, chaves ou endpoints privados no repositório;
- qualquer via que permita associar um registo do Arquivo ao seu autor.

Fora do âmbito:

- conteúdo inadequado submetido por utilizadores (ver secção seguinte);
- vulnerabilidades de serviços de terceiros (assistentes de IA, CDN);
- ausência de autenticação no Arquivo — é uma decisão de desenho, não um defeito.

## Remoção de dados pessoais do Arquivo

O Arquivo é público e o registo é automático. Se uma prompt submetida contiver **nomes, iniciais, números de processo, diagnósticos ou qualquer elemento que permita identificar um aluno**, peça a remoção imediata:

- Email: `frcamposri@gmail.com`
- Assunto: `Remoção urgente — Arquivo EduPrompt`
- Indique o **identificador** do registo (formato `EP-AAMMDD-HHMMSS-código`).

Os pedidos de remoção por dados pessoais têm **prioridade sobre qualquer outro**. Tratamento em **48 horas**.

Enquadramento: RGPD (UE 2016/679) e Lei n.º 58/2019. Dados de saúde são categoria especial ao abrigo do artigo 9.º.

## O que o projeto não recolhe

Nome, conta, endereço IP ou identificador de utilizador. O Arquivo é anónimo quanto à autoria. Os modelos pessoais e os favoritos nunca saem do navegador.
